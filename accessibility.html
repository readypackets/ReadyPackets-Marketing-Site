Accessibility statement

Designed to be usable by more people.

ReadyPackets aims to make this website accessible to visitors using keyboards, assistive technologies, zoom, and different devices.

Accessibility target: this ReadyPackets website is designed and tested against applicable WCAG 2.2 Level AA success criteria. Accessibility is an ongoing practice; this statement does not constitute a legal certification or guarantee of compliance in every circumstance.

What this site includes

  • Semantic landmarks, headings, lists, and link text
  • A visible keyboard focus indicator and skip-to-content link
  • Responsive layout that supports reflow and browser zoom
  • Motion reduction when the visitor requests reduced motion
  • Native, keyboard-operable mobile navigation, dialogs, and FAQ disclosure controls
  • Brand color use selected for readable text contrast
  • Alternative text for meaningful brand images; decorative effects are excluded from the accessibility tree

Need help or found a barrier?

Please contact accessibility@readypackets.com with the page URL, the task you were trying to complete, the assistive technology or browser used if you wish to share it, and a description of the issue. Do not include sensitive personal, portal, order, payment, or document information in e-mail.

Portal accessibility

The authenticated ReadyPackets portal is operated separately. If a portal feature creates a barrier, use the portal’s secure support path where possible or identify the portal location in your accessibility report.
